# ROI Schedule and Visualization Verification

## Desktop

The ROI / Returns workspace renders the staged-capital chart controls, source-link trace, amount-free linked equity prospects, and the 12-month cash-flow schedule grid without horizontal overflow. The return visualization begins in the capital-stage view and retains an explicit unavailable condition for source-return data where no complete return inputs exist.

## Mobile

The workspace preserves the source list, capital-stage controls, return disclosure, and the schedule builder on a narrow viewport. The monthly schedule collapses to a single-column input sequence, maintaining readable month labels, state selection, completion guidance, and the save control.
