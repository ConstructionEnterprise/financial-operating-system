# Cross-Domain ROI Verification

## 2026-08-21 visual review

The ROI / Returns workspace was reviewed at desktop and mobile widths. The audit legend, project selector, and empty-state guard remain visible and usable at both sizes. With no ROI project recorded in the current account, the staged capital stack is intentionally withheld and the interface directs the user to create or select a project first.

When an ROI project is selected, the staged-capital view is designed to show only explicitly linked or exact recorded project/facility-name connections. Potential capital remains pipeline context; committed and funded capital use separate rows and totals; rental quote and actual rental costs remain operating-use exposure rather than capital-stack entries.
