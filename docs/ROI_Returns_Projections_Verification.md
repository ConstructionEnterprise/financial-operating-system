## Data-state conclusion

The live Chappell pilot contains only a 36-month model shell plus empty Downside, Base, and Upside scenario containers. There are no projection assumptions, monthly projection lines, project costs, capital inputs, cash flows, IRR values, payback figures, or ROI results. The visible unavailable states therefore reflect the live data boundary rather than an error condition.
