## Cross-Project Integrity Result

All six projects are now selectable in the **Internal Projects** active-project selector. The database audit confirms that the seed created **six project records, zero project capital needs, zero linked capital opportunities, and zero same-name ROI / Returns models**. Every seeded record retains `missing` data states for total project cost and capital requirement.

> The project record establishes context. Capital needs, capital opportunities, capital-stack stages, cash flows, and returns must be entered or explicitly linked only when supported by separately validated CE/FF information.

## Recommended First Integration Exercise

The **Chappell International Manufacturing Facility** is the appropriate first project to exercise across the operating system because its validated context can eventually touch facility/JV formation, equipment finance, rentals, grants, equity, Factory Foundation operations, logistics, and ROI / Returns. No cross-domain record has been created automatically as part of this seed.
