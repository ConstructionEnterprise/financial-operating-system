# Internal Projects Verification

## Desktop

The Internal Projects section appears immediately below ROI / Returns in the primary sidebar. The desktop workspace renders the command ribbon for Overview, Projects, Capital Needs, Economics, Capital Stack, and Documents, plus an explicit “Project Context · Not a Capital Path” label. The empty state retains missing-data labels rather than populating financial assumptions.

## Mobile

The command ribbon reflows into a readable single-column capability list while preserving all six views. The project selector and portfolio metrics collapse into a single-column layout. The operating-relationship statement remains visible and reinforces that project needs, capital opportunities, staged capital, and ROI / Returns are distinct records.
