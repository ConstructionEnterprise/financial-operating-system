# Texas JV Prospect Source Log

This log records public-source evidence used for the initial Texas JV prospect universe. An organization is a **prospect**, not an endorsement or an approved outreach target. A record may move to **qualified** only after CE/FF reviews the stated fit, project relevance, and outreach approach.

> **Canonical import file:** `docs/CE_FF_Texas_JV_Partner_Prospects_MASTER_import.csv`. It contains **100 unique, source-attributed Texas records** in one six-column schema: organization, archetype, region, official website, source URL, and workflow status. It is the only CSV intended for the JV sourcing import workflow. Earlier `*_sources.csv`, `*_starter.csv`, and `*_expansion.csv` files are retained as research cohorts and audit trail only; they are not canonical import artifacts.

## Data-handling standard

The CSV and application will retain only public business contact channels that an organization publishes itself. Unknown contact, contribution, JV experience, and fit fields must remain explicitly marked **Unknown** rather than being inferred. Public sources must be stored alongside each record, and the initial A/B/C priority is a transparent routing label—not an AI investment recommendation or an instruction to send outreach.
